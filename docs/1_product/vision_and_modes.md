# Vision & Modes

**MONITOR**: Multi-Ontology Narrative Intelligence Through Omniversal Representation

## One-Sentence Pitch
A persistent narrative intelligence system that can build worlds, run solo RPGs, and assist human Game Masters by remembering everything that matters and reacting like a coherent storyteller.

## Core Objectives (What success looks like)
- **O1** Persistent Fictional Worlds: Retain facts, history, entities across sessions.
- **O2** Playable Narrative Experiences: Full solo RPG gameplay, narration, rules enforcement.
- **O3** System-Agnostic Rules: Support multiple RPG systems (dice, cards, etc.).
- **O4** Assisted Human GMing: Co-pilot for tracking, recalling, and analyzing sessions.
- **O5** World Evolution Over Time: Permanent changes based on play.

## System Modes
| Mode | Who Leads | System Role | Target Command Surface |
|------|-----------|-------------|------------------------|
| **Solo Play** | Player | Full GM | web `/play`, `monitor play` |
| **Assisted GM** | Human GM | Memory + Analyst | web `/gm` (GM Assistant) |
| **World Design** | User | Architect | web `/forge`, `monitor manage` |
| **Post-Session Analysis** | User | Archivist | web `/gm` (wrap-up & archive) |

## Non-Goals
The system does **NOT**:
- Force stories toward predefined endings
- Replace player agency
- Require a single RPG system
- Assume combat-only gameplay
