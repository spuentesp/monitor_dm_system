# World-Building Loop

**Intent:** Provide a structured, collaborative session between the user and the `WorldArchitect` to define or expand a setting (entities, axioms, lore) before play begins.

## Key Features
- Operates primarily in **Mode 1 (World Architect)**.
- Facilitates back-and-forth Q&A about world parameters.
- Stages large batches of `ProposedChange` documents for mass-canonization.
