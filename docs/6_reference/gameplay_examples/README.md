## Suggested loop uses

### 1. OOC clarification tests
Use these to check whether the player can ask things like:
- `((what kind of character can I play?))`
- `((what would I roll here?))`
- `((what are the risks before I commit?))`

### 2. Action formatting tests
Use these to confirm the intended style split:
- `*I step into the light and draw his attention.*` → in-fiction action
- `((I am asking out of character how this works.))` → explicit OOC

### 3. Benchmark ideas
Good things to compare across loops or models:
- clarification quality
- mechanical transparency
- consequence framing
- escalation after failed rolls
- transition from pre-play into active play

> These examples are reference material for loop design and playtest benchmarking, not canonical rules text.
